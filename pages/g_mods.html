Extension 16.05 mods

Extension 16.05 can be modded in two ways
  1. JarModding through RetroMCP
  2. Fabric Modding through Cypress Fabric
This guide will explain stuff for Cypress Fabric

Player Setup

CypressFabric officially supports Prism Launcher and it's forks
The following instructions only have to be done once
  1. Download the instance here
  2. Import said instance
  3. Download CypressRepo
  4. Extract the zip archive
  5. Download the Cypress jar file and add it to "com/mojang/minecraft/a1.0.16.05_20" and rename it "minecraft-a1.0.16.05_20.jar"
  6. Run "run_python_server.bat"
  7. Open the instance while the python server is running
  8. Congratulations you succefully installed CypressFabric!

Developer Setup

CypressFabric, like Fabric, uses gradle for it's build system, here are the instructions for creating mods using CypressFabric
  1. Download the example mod here
  2. Download CypressRepo
  3. Extract the zip archive
  4. Download the Cypress jar file and add it to "com/mojang/minecraft/a1.0.16.05_20" and rename it "minecraft-a1.0.16.05_20.jar"
  5. Run "run_python_server.bat", (Note: this is required every time you use gradle)
